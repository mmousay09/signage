# مشغّل الشاشات لأندرويد

تطبيق خفيف يفتح صفحة `/play` بملء الشاشة بدل تطبيق Kiosk خارجي:

- الشاشة تبقى مضاءة، وأشرطة النظام مخفية، وزر الرجوع معطّل.
- الصوت والفيديو يعملان دون لمس الشاشة.
- الإعلانات تُنطق بمحرك الكلام في أندرويد (يعمل حتى إن لم يدعم المتصفح الكلام).
- إن تعطلت الصفحة أو انقطع الاتصال يُعاد التحميل وحده.
- يمكن جعله التطبيق الرئيسي للجهاز فيفتح بعد كل تشغيل.
- خمس لمسات سريعة في الزاوية العلوية تفتح الإعدادات: تغيير الرابط، إعادة التحميل، الخروج.

يبنيه GitHub تلقائيًا عند كل تعديل في هذا المجلد، وتُنشر آخر نسخة في إصدار `android-latest`.
مفتاح التوقيع `signing.keystore` ثابت في المستودع حتى تُثبَّت التحديثات فوق النسخة القديمة.
